# Чӣ тавр боти Telegram-ро ройгон дар сервер ҷойгир кардан мумкин аст

## Файлҳои омодашуда

Ман барои шумо файлҳои зеринро омода кардам:

1. **Procfile** - барои роҳандозии бот дар Render/Heroku
2. **.gitignore** - барои муҳофизати маълумот (токенро пинҳон мекунад)
3. **database.py** - барои нигоҳ доштани маълумоти корбарон дар базаи додаҳо
4. **DEPLOYMENT.md** - дастури муфассал ба забони русӣ
5. **requirements.txt** - бо иловаи psycopg2-binary барои PostgreSQL

## Роҳи осонтарин: Render.com

### Қадами 1: Омода кардани GitHub
```bash
# Дар компютери худ ин корро иҷро кунед:
git init
git add .
git commit -m "Боти омӯзиши забони англисӣ"
git branch -M main
# Баъд аз сохтани репозиторий дар GitHub:
git remote add origin https://github.com/НОМИ_ШУМО/НОМИ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

### Қадами 2: Бақайдгирӣ дар Render
1. Ба [Render.com](https://render.com) равед
2. Бо ҳисоби GitHub ворид шавед
3. Тугмаи "New +" -ро пахш кунед → "Web Service"

### Қадами 3: Танзимоти сервис
- **Name:** english-quiz-bot (ё ягон номи дигар)
- **Region:** Frankfurt (барои Тоҷикистон наздиктар)
- **Branch:** main
- **Runtime:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- **Instance Type:** Free

### Қадами 4: Илова кардани BOT_TOKEN
1. Дар бахши "Environment" тугмаи "Add Environment Variable" -ро пахш кунед
2. Номи тағйирёбанда: `BOT_TOKEN`
3. Қиммат: токени боти шумо (аз @BotFather гирифташуда)

### Қадами 5: Эҷод кардан
Тугмаи "Create Web Service" -ро пахш кунед ва интизор шавед, ки бот роҳандозӣ шавад.

## Муҳим: Нигоҳ доштани маълумот

Боти шумо маълумоти корбаронро дар файли `users_data.json` нигоҳ медошт. Дар серверҳои абрӣ ин файл метавонад нест шавад! 

Ман модули нави `database.py` -ро илова кардам, ки:
- Автоматикӣ SQLite -ро дар маҳал истифода мебарад
- Автоматикӣ PostgreSQL -ро дар Render/Heroku истифода мебарад
- Маълумот ҳамеша нигоҳ дошта мешавад

Барои фаъол кардани PostgreSQL дар Render:
1. Дар Render "New +" → "PostgreSQL" -ро интихоб кунед
2. Тарифи ройгонро интихоб кунед (то 1GB)
3. Пас аз эҷод, DATABASE_URL -ро ба Environment Variables илова кунед

## Санҷиши кор

Баъд аз роҳандозӣ:
1. Ба боти худ равед
2. `/start` -ро фиристед
3. Бот бояд ҷавоб диҳад

Агар хатогӣ бошад:
- Дар Render ба бахши "Logs" равед
- Хатогиҳоро санҷед
