# Телеграм-бот для изучения английского языка 🇬🇧

Интерактивный телеграм-бот для проведения тестов по английскому языку с игровыми механиками, социальными функциями и системой в стиле Duolingo.

## Возможности ✨

### 🏆 Система лиг (как в Duolingo)
- **Еженедельные лиги**: Соревнуйтесь с другими пользователями в вашей лиге
- **Повышение и понижение**: Лучшие пользователи повышаются, худшие понижаются
- **Уровни лиг**:
  - 🥉 **Бронзовая лига** → 🥈 **Серебряная лига** → 🥇 **Золотая лига**
  - 💎 **Платиновая лига** → 💠 **Алмазная лига** → 👑 **Мастер лига** → 🏆 **Чемпион лига**
- **Очки лиги**: Зарабатывайте очки, правильно отвечая на вопросы
- **Еженедельный сброс**: Лиги обновляются каждые 7 дней с повышениями/понижениями

### 👥 Система друзей
- **Добавление друзей**: Отправляйте и принимайте запросы в друзья по ID
- **Поддержка друзей**: Отправляйте сердца друзьям, которым они нужны
- **Соревнования**: Видьте своих друзей в таблице лиги
- **Команды**:
  - `/myid` - Получить ваш ID для добавления в друзья
  - `/addfriend <user_id>` - Отправить запрос в друзья
  - `/acceptfriend <user_id>` - Принять запрос в друзья

### 💎 Система сердец (как в Duolingo)
- **Ограниченные сердца**: У вас максимум 5 сердец
- **Восстановление**: 1 сердце восстанавливается каждый час
- **Система поддержки**: Друзья могут отправлять вам сердца
- **Визуальное отображение**: Видьте свои сердца как ❤️/🖤 иконки

### ⚠️ Система потери уровня
- **Оставайтесь активными!**: Если не играть 1 день, ваш уровень уменьшается
- **Прогрессивная потеря**: Теряйте 1 уровень за каждый день неактивности
- **Минимальный уровень**: Не может быть ниже 1 уровня
- **Сброс таймера**: Пройдите тест, чтобы сбросить таймер
- **Команда**: `/decay` - Проверить статус потери уровня

### 🎮 Игровая система прогресса
- **Отслеживание прогресса**: Все данные сохраняются в `users_data.json`
- **Постоянный прогресс**: Бот помнит уровень, очки и звание каждого ученика
- **Система званий** (как в Free Fire):
  - 🥉 **Бронза**: 0+ очков
  - 🥈 **Серебро**: 50+ очков
  - 🥇 **Золото**: 150+ очков
  - 💎 **Платина**: 300+ очков
  - 💠 **Алмаз**: 500+ очков
  - 👑 **Мастер**: 800+ очков
  - 🏆 **Гранд Мастер**: 1200+ очков
  - ⚜️ **Легенда**: 2000+ очков

### 📚 Уровни тестов
- **102 уровня**: От новичка до профи
- **Прогрессивная сложность**: Уровни становятся сложнее
- **Автоматическая разблокировка**: Пройдите уровень с 60%+ результатом, чтобы открыть следующий
- **Лучшие результаты**: Отслеживайте свои лучшие результаты по уровням

### 🎤 Голосовой режим
- Учащиеся могут отправлять голосовые сообщения вместо нажатия кнопок
- Использует Google Speech Recognition API
- Говорите ответ чётко (например, "is", "went", "children")

### 📊 Мой прогресс
- Просматривайте текущее звание и общее количество очков
- Смотрите статистику точности
- Проверяйте лучшие результаты по уровням
- Отслеживайте прогресс до следующего звания

## Установка 🚀

### Требования
- Python 3.8+
- Токен телеграм-бота (получите у @BotFather)

### 1. Скачайте файлы бота

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте бота
Отредактируйте `config.py` и добавьте токен вашего телеграм-бота:
```python
BOT_TOKEN = "ваш_токен_бота"
```

### 4. Запустите бота
```bash
python main.py
```

## Зависимости 📦

- **aiogram** >= 3.0.0 - Фреймворк для телеграм-ботов
- **aiofiles** >= 23.1.0 - Асинхронные файловые операции
- **SpeechRecognition** >= 3.10.0 - Распознавание речи
- **pydub** >= 0.25.1 - Обработка аудио
- **ffmpeg-python** >= 0.2.0 - Привязки FFmpeg

### Дополнительные системные требования для голосового режима
Для работы распознавания речи нужно установить FFmpeg:

**Установка на Windows:**
1. Скачайте FFmpeg с [ffmpeg.org](https://ffmpeg.org/download.html) (версия essentials)
2. Распакуйте ZIP в `C:\ffmpeg`
3. Добавьте `C:\ffmpeg\bin` в системный PATH:
   - Правой кнопкой "Этот компьютер" → Свойства → Дополнительные параметры системы
   - Нажмите "Переменные среды"
   - Найдите "Path" в системных переменных → Изменить → Создать
   - Добавьте `C:\ffmpeg\bin` → ОК

**Быстрая установка через Chocolatey:**
```powershell
choco install ffmpeg
```

**Linux:**
```bash
sudo apt-get install ffmpeg  # Ubuntu/Debian
sudo yum install ffmpeg      # CentOS/RHEL
```

**macOS:**
```bash
brew install ffmpeg
```

## Как использовать 📖

### Начало работы
1. **Запустите бота**: Отправьте `/start` боту
2. **Выберите уровень**: Выберите из доступных уровней
3. **Отвечайте на вопросы**: Нажмите на правильный ответ ИЛИ используйте голосовой режим
4. **Включите голосовой режим**: Нажмите "🎤 Голосовой режим" для переключения

### Социальные функции
5. **Получите ваш ID**: Используйте `/myid` для получения вашего ID
6. **Добавьте друзей**: Используйте `/addfriend <user_id>` для отправки запросов
7. **Примите запросы**: Используйте `/acceptfriend <user_id>` для принятия запросов
8. **Поддержите друзей**: Перейдите в меню Друзья → Поддержать друга для отправки сердец

### Соревнования и прогресс
9. **Проверьте лигу**: Нажмите "🏆 Лига" для просмотра таблицы
10. **Просмотрите сердца**: Нажмите "💎 Сердца" для просмотра статуса
11. **Проверьте потерю уровня**: Используйте `/decay` для проверки статуса
12. **Мой прогресс**: Нажмите "📊 Мой прогресс" для просмотра статистики

## Команды бота 📋

| Команда | Описание |
|---------|-------------|
| `/start` | Запустить бота и увидеть главное меню |
| `/myid` | Получить ваш ID для добавления в друзья |
| `/addfriend <id>` | Отправить запрос в друзья пользователю |
| `/acceptfriend <id>` | Принять запрос в друзья |
| `/decay` | Проверить статус потери уровня |

## Система очков ⭐

- Каждый правильный ответ даёт **2 очка**
- Очки влияют как на звание, так и на позицию в лиге
- Очки лиги сбрасываются еженедельно с повышениями/понижениями

## Хранение данных 💾

Данные пользователей хранятся в `users_data.json` и включают:
- Общие очки и очки лиги
- Всего правильных ответов и точность
- Текущий уровень и разблокированные уровни
- Текущее звание и лига
- Лучший результат по уровням
- Сердца и время восстановления
- Список друзей и ожидающие запросы
- Время последней активности (для отслеживания потери уровня)

## Игровые механики 🎯

### Система лиг
- Пользователи группируются в лиги до 30 человек
- Зарабатывайте очки лиги, проходя тесты
- Топ-5 пользователей повышаются в конце недели
- Последние 3 пользователя понижаются в конце недели
- Очки лиги сбрасываются каждые 7 дней

### Система сердец
- Максимум 5 сердец
- 1 сердце восстанавливается каждый час
- Друзья могут отправлять вам сердца (вы теряете 1, они получают 1)
- Сердца нужны для прохождения уровней

### Система потери уровня
- Если неактивны 1+ дней, ваш уровень уменьшается
- Теряйте 1 уровень за каждый день неактивности
- Минимальный уровень - 1 (не может быть ниже)
- Пройдите любой тест, чтобы сбросить таймер

## Решение проблем 🔧

### Голосовое распознавание не работает?
1. Убедитесь, что FFmpeg установлен и в PATH
2. Проверьте интернет-соединение (Google API требует подключения)
3. Говорите чётко в тихой обстановке

### Уровень заблокирован?
- Пройдите предыдущие уровни с результатом 60%+, чтобы открыть следующий

### Не могу добавить друга?
- Убедитесь, что у вас правильный ID (используйте `/myid`)
- Пользователь должен существовать в системе бота

### Предупреждение о потере уровня?
- Пройдите тест, чтобы сбросить таймер активности
- Используйте `/decay` для проверки статуса

### Бот не запускается?
- Проверьте токен бота в `config.py`
- Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
