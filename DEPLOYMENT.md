# Инструкция по развертыванию Telegram-бота на бесплатных серверах

## Вариант 1: Render.com (Рекомендуется)

Render.com предоставляет бесплатный тариф для Worker сервисов.

### Шаги:

1. **Зарегистрируйтесь на [Render.com](https://render.com)**

2. **Подготовьте репозиторий на GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. **Создайте Worker сервис на Render:**
   - Нажмите "New +" → "Web Service"
   - Подключите ваш GitHub репозиторий
   - Настройте:
     - **Name:** english-quiz-bot (или любое имя)
     - **Region:** Frankfurt (ближе к Таджикистану)
     - **Branch:** main
     - **Root Directory:** (оставьте пустым)
     - **Runtime:** Python 3
     - **Build Command:** `pip install -r requirements.txt`
     - **Start Command:** `python main.py`
     - **Instance Type:** Free

4. **Добавьте переменные окружения:**
   - В разделе "Environment" добавьте:
     - `BOT_TOKEN` = ваш токен бота

5. **Deploy!** Нажмите "Create Web Service"

### Важно:
- Бесплатный тариф имеет лимит 750 часов в месяц (достаточно для 1 бота)
- Worker сервисы не "засыпают" в отличие от Web Services
- Для хранения данных используйте внешнюю базу данных (см. ниже)

## Вариант 2: Railway.app

Railway предоставляет $5 бесплатных кредитов ежемесячно.

### Шаги:

1. **Зарегистрируйтесь на [Railway.app](https://railway.app)** через GitHub

2. **Создайте новый проект:**
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Выберите ваш репозиторий

3. **Настройте сервис:**
   - Railway автоматически обнаружит Python проект
   - Добавьте переменную окружения `BOT_TOKEN`

4. **Deploy!**

## Вариант 3: Heroku (с ограничениями)

Heroku больше не предоставляет полностью бесплатный тариф, но есть альтернативы.

### Шаги:

1. **Установите Heroku CLI**

2. **Залогиньтесь:**
   ```bash
   heroku login
   ```

3. **Создайте приложение:**
   ```bash
   heroku create english-quiz-bot
   ```

4. **Добавьте переменные окружения:**
   ```bash
   heroku config:set BOT_TOKEN=ваш_токен
   ```

5. **Deploy:**
   ```bash
   git push heroku main
   ```

6. **Включите Worker:**
   ```bash
   heroku ps:scale worker=1
   ```

## ⚠️ КРИТИЧЕСКИ ВАЖНО: Хранение данных

Ваш бот использует файл `users_data.json` для хранения данных пользователей. На облачных платформах файловая система **временная** и данные могут быть потеряны при перезапуске!

### Решение 1: Использовать базу данных (Рекомендуется)

Добавьте в `requirements.txt`:
```
psycopg2-binary>=2.9.0  # для PostgreSQL
# или
pymongo>=4.0.0  # для MongoDB
```

### Решение 2: Использовать Redis Cloud (бесплатно 30MB)

### Решение 3: Использовать MongoDB Atlas (бесплатно 512MB)

   - Бесплатный тариф (до 1GB)

3. **Обновите код бота** для использования базы данных

## Проверка работы

После деплоя проверьте:

1. Бот отвечает на `/start`
2. Данные пользователей сохраняются
3. Голосовые сообщения работают (требуется ffmpeg)

### Для голосовых сообщений на Render:
Render автоматически устанавливает ffmpeg, но если возникнут проблемы, создайте `Aptfile`:
```
ffmpeg
```
